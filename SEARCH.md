# Native online search

The confirmed working search fix changes three branch instructions in classes3.dex from the last-launching catalog build. It preserves the DEX size, registers, code offsets, metadata and original native provider. The script requires that exact input and checks the original bytes before writing. Its output is unsigned and must be aligned and signed locally with your own private key.

The prior full-reassembly online-search candidate failed to launch on the test phone and was superseded. The direct branch-patch candidate launched and search was confirmed working.
