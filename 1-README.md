# Music Ultra

Customized RVX Music for Android, with Library first, Search in the middle and Explore last. The bottom bar uses outline icons. Search opens the original native search UI.

## Download

Use the latest release. Package: `app.rvx.android.apps.youtube.musix`. App name: **Music Ultra**.

## Change history

The commits in this repository reconstruct the requested customization stages from preserved source and APK snapshots. They are newly recorded commits, not the original editing timestamps. Patches contain the differences only, not a full upstream application source distribution. The final released APK is the phone-confirmed build supplied on 19 November 2026.

Failed or superseded candidates are documented separately and are not the latest release.

## Scope

This repository tracks Music Ultra. YouTube Ultra integration is separate work. Signing keys and credentials are never included.
